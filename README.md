# Sevi — мессенджер нового поколения

Полностью клиентский (HTML/CSS/JS, без сборки) прототип веб-мессенджера **Sevi**: ультрасовременный dark mode с глассморфизмом, фиолетово-зелёными акцентами и плавными анимациями.

## Возможности

- **Многоуровневая навигация** (как в Discord/Telegram): рейл серверов, папки чатов (Все / Личные / Группы / Каналы), поиск.
- **Чаты**: личные (тестовый чат с **Bulat**), группы (**Sevenis**), публичные каналы. Отправка сообщений с авто-ответом.
- **Голосовые комнаты и видеозвонки**: баннер голосовой комнаты, модальное окно звонка с **демонстрацией экрана**, переключением микрофона/камеры/screen-share (заглушки под WebRTC) и таймером.
- **Стрики с питомцами**: вместо «огонька» — виртуальный питомец (🐶 Собачка / 🐱 Кошечка / 🦆 Уточка). Питомец радуется при росте стрика, грустит при угрозе и засыпает, когда стрик сгорает. Счётчик дней + прогресс-бар.
- **Музыкальный плеер уровня Spotify**: обложка, таймлайн с перемоткой, Play/Pause/Next/Prev/Shuffle/Repeat, плейлисты (Cafe / Bar / Focus) и индикатор **совместного прослушивания** с собеседником.

## Запуск

Откройте `index.html` в браузере — внешних зависимостей нет.

```bash
# либо локальный сервер:
python3 -m http.server 8000
# затем http://localhost:8000
```

## Структура

| Файл | Назначение |
|------|------------|
| `index.html` | Семантическая разметка: рейл, список чатов, окно переписки, модалка звонка, плеер. |
| `style.css` | Переменные `:root`, Flexbox/Grid, эффекты `backdrop-filter`, анимации hover. |
| `script.js` | Переключение чатов, фильтры/поиск, система стриков с питомцами, плеер, видеозвонок. |
